# To‑Do List (Local Storage)

A small vanilla JavaScript to‑do list that saves tasks in the browser using localStorage.

How to run
1. Save the files (index.html, styles.css, app.js) into the same folder.
2. Open index.html in your browser.

Features
- Add tasks
- Edit tasks (double-click label or press Edit)
- Mark complete / uncomplete
- Filter: All / Active / Completed
- Clear completed
- Persistent via localStorage (key: `todos-v1`)
